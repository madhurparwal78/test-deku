## BLOCKING PREREQUISITES

1. **The image digests.** `python:3.12-slim-bookworm@sha256:782412e8...`,
   `postgres:16.4-bookworm@sha256:e62fbf9d...` and
   `quay.io/minio/minio:RELEASE.2024-10-13T13-34-11Z@sha256:9535594a...` are pinned. The MinIO image
   comes from the project's own quay.io registry because Docker Hub answered 401 to the digest
   lookup. Confirm all three still resolve before the first build.
2. **Node 22 is added over the Python base.** The drawn stack is Express with Nunjucks and HTMX on
   Node.js 22; the image installs Node from the NodeSource registry. If that key or repository
   moves, G13 fails before anything else.
3. **`deku-verifier-base:0.2` must exist.** Under `environment_mode = "separate"` the grader runs
   in the image `tests/Dockerfile` builds on that base. The storage tests need the base's
   `capabilities.make_store()` with boto3, and the page tests need Playwright with Chromium.
4. **The bucket exists before the app starts.** `minio-init` creates `deku`, sets its anonymous
   policy to none and reports healthy only once the bucket answers; `main` waits on it.
5. **No unresolved provider.** `backend` -> `postgres` and `storage` -> `minio` both resolve to
   real fragments. NONE outstanding.

## WHAT THE ORACLE MUST GET RIGHT FIRST

1. **The seed rule.** Every `result` count, generated cell by cell from the respondents table and
   the rates and shifts, rounded down, with `remainder` options and tenths for `tool-count`. Every
   expected figure in the graders is computed from that rule by the resolver in `tests/conftest.py`.
2. **One query layer.** Headings, rows, takeaways, the export and the citation must come from one
   resolution; the export test compares every table row with the chapter API for three segments.
3. **Rounding and states.** A movement is rounded once from full precision (the daily rise is 16,
   not 17), and the movement states, suppression at 30 and the 1.96 difference test decide every
   heading form.
4. **The library boundary.** Another reader's download and removal answer 404, a download with no
   session answers 401, and a saved object's bytes equal `GET /api/export.md` for the same segment.
5. **The segment swap.** The `Company size` select must be labelled so, the change must swap the
   chapter body without a reload, and exactly one live announcement must read
   `Now showing <label>, <base> respondents.`

## KNOWN UNPROVEN

No reference code exists yet. Nothing in this bundle has been compiled, started or run. The
76 pytest tests in `tests/test_output.py` and the 37 browser substeps have never executed
against an application. The expected figures were checked against an independent Python
implementation of the brief's arithmetic, which is embedded in `tests/conftest.py`, so an error in
that resolver and in the brief would agree with each other. The Playwright tests are the most
exposed: they locate the segment select by the label `Company size`, the rail's current entry by
`aria-current` inside a navigation landmark, and live announcements by `aria-live` or a status
role.

The seven certification prompts were run by the same agent that authored the artifacts, so every
QC verdict in the report is SELF-ATTESTED. The kit's rule is `owner != verifier`; an independent
reviewer pass is worth running before the bundle is counted.
