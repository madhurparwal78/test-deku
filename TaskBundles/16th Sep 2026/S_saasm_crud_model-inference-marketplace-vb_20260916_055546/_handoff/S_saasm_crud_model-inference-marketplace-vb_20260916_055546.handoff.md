## BLOCKING PREREQUISITES

1. **The base image digests.** `python:3.12-slim-bookworm@sha256:782412e8...` and
   `postgres:16.4-bookworm@sha256:e62fbf9d...` are the pins the kit's reference environment
   carries. Confirm both still resolve before the first build.
2. **`deku-verifier-base:0.2` must exist.** Under `environment_mode = "separate"` the
   grader runs in the image `tests/Dockerfile` builds on that base, which supplies
   `pytest.ini`, `score.py`, `run_workflows.py`, `run_rubric.py`, `capabilities.py`,
   `appclient.py` and `_shapes.py` on `PYTHONPATH=/tests`. The bundle ships only `test.sh`,
   per CON-2.

## WHAT THE ORACLE MUST GET RIGHT FIRST

The three surfaces that decide whether a correct app scores, in the order they bite:

1. **The meter.** `usage_records.prediction_id` is unique across the whole table, and a
   second report of one completed prediction must add no row. Four tests and one browser
   chain read this.
2. **Idempotency.** `(account_id, idempotency_key)` is unique wherever the key is present.
   Twenty concurrent creates carrying one key must yield one prediction.
3. **Tenancy.** An unauthorised read of a record that exists answers as a missing record,
   never as a refusal, for every resource type.
