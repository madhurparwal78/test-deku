## WHAT THE ORACLE MUST GET RIGHT FIRST

1. **The draft boundary.** `/works/veloce`, `/api/works/veloce` and `/media/<key>` for each of
   Veloce's five objects answer `404` to a visitor and to a reader, by bearer token and by
   cookie, while every object stays in the store. The bucket carries no anonymous read.
2. **The key scheme.** `works/{work_id}/{sha256_of_bytes}.{ext}` with the lowercase hex digest
   of the uploaded bytes; the same bytes twice store one object; removing an image removes the
   object.
3. **Seeding.** One cover and four gallery objects per case study, generated, uploaded once, and
   exactly matched by `media` rows. Tables are named as the entities.
4. **Enquiries.** Every field rule answers its pinned message with `field`; a reader reads only
   their own and another reader's answers `404` at `GET /api/enquiries/{id}`.
5. **The films.** Each film is a `video` element, muted, looping, without controls, with a
   caption track; the SOUND toggle exposes a pressed state.

## KNOWN UNPROVEN

No reference code exists yet. Nothing in this bundle has been compiled, started or run. The
107 pytest tests in `tests/test_output.py` and the 64 browser substeps have never executed
against an application: they are authored against the brief's pinned literals and API shapes,
and the first oracle run is where they are first exercised. The Playwright-driven tests are the
most exposed: they read computed styles, locate the menu control by an accessible name containing
"menu", the SOUND toggle by `aria-pressed` or `aria-checked`, and the work label by its `VIEW`
text, and they wheel through the home route to reach the film bands.

The seven certification prompts were run by the same agent that authored the artifacts, so
every QC verdict in the report is SELF-ATTESTED. The kit's rule is `owner != verifier`; an
independent reviewer pass is worth running before the bundle is counted.
